# Телеграмм Веб-Приложение для Заказа еды

Идея проекта заключается в создании Telegram веб-приложения, через которое посетители заведения могут удобно и быстро оформить заказ еды прямо со своего телефона. Пользователю не нужно ждать официанта — он сканирует QR-код на столе, выбирает блюда из меню, оформляет заказ и отслеживает его статус. Это ускоряет обслуживание, снижает нагрузку на персонал и повышает комфорт гостей.

Киллер-фича проекта — система лояльности: за каждый заказ пользователь получает бонусы, которые можно потратить на персонализированную программу тренировок или готовую диету, тем самым интегрируя питание в здоровый образ жизни.
