# 📊 Инвестиционная презентация — QR‑FOOD

## 1. Краткое описание  
**QR‑FOOD** — это Telegram WebApp, позволяющее посетителям кафе и ресторанов быстро и удобно оформить заказ еды прямо со своего телефона.  
Пользователь сканирует QR‑код на столе, выбирает блюда в интерактивном меню, оформляет заказ и отслеживает его готовность — всё внутри Telegram, без установки приложений.

🧠 **Киллер-фича:** За лояльность (частые заказы) пользователи получают **бонусы**, которые можно обменять на **персональные диеты** или **тренировочные программы**, тем самым совмещая питание и заботу о здоровье.

---

## 2. Проблема  
- Очереди и долгие ожидания официанта.  
- Ошибки при передаче заказов.  
- Недостаток персонала.  
- Отсутствие цифрового взаимодействия с меню.  
- Низкий уровень вовлечённости и повторных визитов.

---

## 3. Решение  
**QR‑FOOD** решает все эти проблемы:
- Заказ еды через Telegram без ожидания официанта.  
- QR‑код на столе → быстрое меню → оформление заказа → отслеживание.  
- Увеличение комфорта и скорости обслуживания.  
- Программа лояльности с **настоящими бонусами** — ЗОЖ‑мотивацией.
