# Гипотеза бизнес-модели

1. Продажа блюд — пользователь оформляет заказ еды напрямую через Telegram веб-приложение, сканируя QR-код на столе. Это упрощает и ускоряет процесс заказа, снижает нагрузку на персонал и повышает лояльность гостей.

2. Цены и акции — все блюда доступны по актуальным ценам, с возможностью участия в акциях и спецпредложениях, которые автоматически отображаются в приложении. Это стимулирует заказы и повышает средний чек без дополнительной нагрузки на сотрудников.

3. Бонусы и программы здоровья — пользователь копит бонусы в программе лояльности и может обменять их на программы тренировок и готовые диеты. Это расширяет функционал, повышает вовлечённость и удержание клиентов.
