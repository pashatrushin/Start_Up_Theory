# Гипотеза бизнес-модели

1. Продажа блюд — пользователь оформляет заказ еды напрямую через Telegram веб-приложение, сканируя QR-код на столе. Это упрощает и ускоряет процесс заказа, снижает нагрузку на персонал и повышает лояльность гостей.

2. Цены и акции — все блюда доступны по актуальным ценам, с возможностью участия в акциях и спецпредложениях, которые автоматически отображаются в приложении. Это позволяет стимулировать заказы и повышать средний чек без дополнительной нагрузки на сотрудников.
